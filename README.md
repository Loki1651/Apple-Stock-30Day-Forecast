# Apple-Stock-30Day-Forecast
End-to-end time-series forecasting project that predicts Apple (AAPL) stock prices for the next 30 days using a tuned SARIMA model. Includes data preprocessing, model training, serialization, and deployment through a responsive Streamlit dashboard with key metrics and visualization.
#  Apple Stock Forecasting App
### 30-Day Forecast using SARIMA | Streamlit Dashboard

##  Tech Stack
Python • Pandas • Statsmodels • Streamlit • Time Series

##  How to Run
streamlit run app.py

##  Features
- 30-Day forecast
- Interactive sidebar
- Metrics dashboard
- Forecast chart

##  Challenges Faced
- Negative forecasts fixed by constraints
- Model convergence tuning
- Deployment permission issues solved
